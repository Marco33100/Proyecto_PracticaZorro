# Proyecto_PracticaZorro

Proyecto 2D en Unity con un personaje de zorro, movimiento horizontal, animaciones y un escenario con tiles.

## Requisitos

- Unity Hub.
- Unity Editor **6000.3.23f1**.

## Abrir el proyecto

1. Clona o descarga este repositorio.
2. En Unity Hub, selecciona **Add / Agregar** y elige la carpeta del proyecto.
3. Abre el proyecto con Unity **6000.3.23f1** y espera a que se importen los recursos y paquetes.
4. Abre `Assets/Scenes/SampleScene.unity` y pulsa **Play**.

## Estructura

- `Assets/`: escenas, scripts, sprites, animaciones y tiles, con sus archivos `.meta`.
- `Packages/`: dependencias del proyecto.
- `ProjectSettings/`: configuración de Unity.

Unity regenera las carpetas de caché, como `Library` y `Temp`, al abrir el proyecto. Estas carpetas se excluyen mediante `.gitignore`.
